# QUAL Score Project
### Task: Evaluating educational feedback and assessment in research.

### Data: There are a total of 1509 comments that have been rated by two raters. Each comment was scored using the QuAL score (Quality of Assessment for Learning), a 0-5 point scale rating system based on the summation of a score of evidence (0-3 points), suggestion (0-1 point), and connection (0-1 point). If the total QuAL scores showed a difference of more than 1 point between the two raters, that comment was then scored by a third rater.
